# Gemini 原型提示词

下面这版提示词可以直接复制给 Gemini，用于生成阿尔茨海默病 AI+体感康复平台的多角色高保真原型方案。

---

你是一名资深产品设计师和医疗康复类 SaaS 设计专家，请为我设计一个 **“阿尔茨海默病 AI+体感康复平台”** 的 **多角色高保真原型方案**。

请严格按以下要求执行，不要泛泛而谈，不要只给概念，要给出**可直接进入 Figma 或原型绘制的页面级方案**。

## 一、项目背景

这是一个面向阿尔茨海默病及轻中度认知障碍人群的数字康复平台，核心闭环是：

**建档/同意 -> AI评估 -> 风险分级 -> 康复计划 -> 训练执行 -> 训练结果 -> 医师调整**

平台的目标不是做一个普通健康 App，而是同时满足三类核心角色：

1. **患者端**
   - 低认知负担
   - 能完成评估和训练
   - 有明确鼓励反馈

2. **医师端**
   - 能快速查看患者状态
   - 能确认风险分级
   - 能编辑和调整康复计划
   - 能查看训练记录和异常

3. **管理员端**
   - 管理账号、角色、训练内容、系统配置、审计日志
   - 默认不直接查看患者敏感病历详情

家属端本轮不是重点，可以只保留扩展建议，不用做完整高保真。

## 二、设计目标

请为这个平台输出一套 **高保真 UI 原型方案**，要求：

- 整体风格统一
- 患者端、医师端、管理员端信息密度明显不同
- 可以直接给前端开发参考
- 覆盖关键状态、空状态、错误状态

## 三、视觉方向

请采用以下视觉方向：

### 视觉关键词

- 温暖
- 专业
- 安全
- 鼓励感
- 可解释智能
- 非冰冷医院风
- 非娱乐化游戏风

### 风格定义

请采用 **“Warm Clinical Calm”** 风格：

- 主色：低饱和蓝绿，传达稳定、信任、康复
- 辅色：暖杏色、米金色，用于鼓励和完成反馈
- 患者端更柔和、更大字号、更少干扰
- 医师端更稳重、更高信息密度
- 管理员端更克制、更中性、偏治理后台

### 建议色板

- brand-900: `#173945`
- brand-700: `#1F5D70`
- brand-500: `#2E8297`
- brand-300: `#8FC6D1`
- brand-100: `#E6F4F7`
- accent-mint: `#B9E2D5`
- accent-apricot: `#F3B489`
- accent-gold: `#E5C76C`
- success-600: `#1E7A5A`
- warning-600: `#B97922`
- error-600: `#B14848`
- info-600: `#3D73B8`

### 字体建议

- 中文主字体：HarmonyOS Sans SC / Source Han Sans SC / Noto Sans SC
- 数字辅助字体：IBM Plex Sans
- 患者端正文默认不低于 18px
- 医师端正文默认 16px
- 后台表格正文默认 14px

## 四、交互原则

### 患者端

- 一屏只做一件事
- 一个页面只保留一个主 CTA
- 主按钮要大、清晰、好点
- 错误提示必须告诉用户下一步怎么做
- 语言口语化，避免复杂医疗术语

### 医师端

- 强调检索、判断、确认、调整
- 风险等级、计划状态、异常状态必须首屏明显
- 页面应支持高信息密度，但结构要清晰

### 管理员端

- 强调账号可控、内容可管、日志可查
- 页面要像稳定治理后台
- 危险操作必须有明确确认

## 六、状态页要求

原型中必须覆盖这些关键状态：

- 首次进入
- 无数据
- 无训练计划
- 未授权摄像头/麦克风
- 评估失败
- 训练中断
- 结果同步失败
- 高风险提醒
- 计划暂停
- 越权访问被拒绝
- 管理员危险操作确认
