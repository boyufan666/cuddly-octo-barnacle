# 客户上线资料准备清单

本文用于正式交付和上线前向客户确认资料。目标是保证系统可以真实采集数据，而不是依赖演示账号、示例数据、个人免费 token 或 mock 服务。

如果需要先给客户发送短版资料索取口径，可直接使用 `docs/customer-final-input-request.md`。客户回复后，按 `docs/customer-input-to-launch-gate-runbook.md` 整理为本文件对应的结构化资料包并执行门禁。

客户可从 `docs/templates/customer-production-input.template.json` 复制后填写结构化资料包。模板文件只展示字段结构，原样会被校验脚本拒绝；必须替换为客户确认后的正式资料，然后执行：

```bash
pnpm verify:customer-production-input -- <customer-production-input.json>
```

该命令只校验客户材料和证据完整性，不会联网、不读取 `.env`、不替代 `pnpm delivery:check:production`，也不替代真实 AI/语音调用验收或浏览器体感实机验真。

## 基础上线资料

- 正式域名：Web 域名、API 域名和是否使用内网域名。
- 服务器资源：CPU、内存、磁盘、带宽、部署区域和是否允许 Docker。
- HTTPS 证书：证书申请方式、续期责任人和反向代理方案。
- 数据库与 Redis：正式连接地址、账号、密码、备份周期和恢复要求。
- 管理账号：超级管理员、运营管理员、审计查看人员的实名账号清单。
- 机构与医师资料：机构名称、编码、医师姓名、科室、职称和账号开通方式。
- 隐私协议：协议正文、版本号、生效日期、授权撤回规则和客户盖章确认版本。
- 试点患者资料：是否使用真实患者、测试患者或脱敏患者，以及数据录入责任人。

## AI 与语音资料

正式 AI/语音评估不是必填演示项，但如果客户要求上线真实大模型或语音能力，必须提供以下资料：

如果客户明确一期不要求真实 AI/语音上线，资料包中可将 `ai.requiredForLaunch` 和 `speech.requiredForLaunch` 设为 `false`；此时只能交付结构化评估录入和接口边界，不能宣传真实 AI/语音评估已完成。

免费优先供应商选型、试用额度评估维度和生产可用性判断见 `docs/ai-speech-provider-selection-free-first.md`。该文档仅用于选型沟通，不替代客户资料包校验、生产环境变量检查、真实调用日志或医师人工复核证据。

- 大模型供应商账号：优先使用客户已有星火账号；也可评估通义千问、智谱、DeepSeek、Moonshot、OpenAI 等供应商当期免费额度或试用额度。
- 语音识别供应商账号：可优先评估客户已有星火/讯飞语音能力或其他带免费额度的语音转文字服务。
- 费用确认：免费额度、QPS、并发、有效期、超额计费和是否允许生产使用。
- 正式 endpoint：必须是供应商或客户网关提供的 HTTPS 地址，不能是 localhost、mock、demo 或临时代理。
- 密钥托管：只提供 `secret-manager://...` 或客户正式密钥管理方案中的引用，不把真实密钥写入文档、代码或前端环境变量。
- 模型版本：大模型名称、模型版本、语音识别模型版本和后续升级责任人。
- 提示词版本：评估提示词版本、维护人、审批记录和变更记录。
- 数据合规：确认是否允许把健康数据、问答转写和评估摘要发送给第三方供应商。
- 调用日志：至少保留调用 ID、时间、模型版本、脱敏请求摘要、脱敏响应摘要、错误码和关联评估记录。
- 人工复核：医师复核人、复核时间、复核结论和复核记录保存方式。

优先免费方案可以作为试点降成本路径，但不能把个人免费 token、临时试用代理或无法留存调用日志的服务作为生产交付依据。免费额度到期、欠费、接口关闭或供应商限制导致能力不可用时，系统必须阻断真实 AI/语音评估，不允许自动降级为 mock 或伪造 AI 结果。

## 体感游戏与设备资料

- 浏览器体感路线：确认一期至少一个浏览器体感训练游戏作为正式训练内容。
- 设备要求：验收使用的电脑、浏览器版本、摄像头型号、网络环境和训练场地光线。
- Unity 资源：如果客户已有 Unity 游戏，需提供 WebGL Build、`manifest.json`、版本号、Bridge 协议适配说明和授权使用证明。
- 训练指标：确认 `reaction_time_ms`、`target_hit_rate`、`pose_visibility_avg`、`arm_raise_accuracy` 是否满足客户验收。
- 训练安全说明：适用人群、禁忌、训练时长、异常停止条件和现场陪护要求。

## 验收证据

- 账号权限截图：患者、家属、医师、管理员、审计角色各一组。
- 评估证据：结构化评估记录；如接入真实 AI/语音，还需供应商调用日志和人工复核记录。
- 训练证据：浏览器体感 evidence JSON、截图、录屏、训练记录 API 和审计日志 API 验真结果。
- 数据导出证据：脱敏导出样例和导出审计日志。
- 部署证据：HTTPS、域名、备份、监控、日志留存和密钥托管配置截图或清单。

## 未提供即阻断

以下任一项缺失时，不应宣布真实上线完成：

- 正式域名、HTTPS、生产数据库/Redis 或备份策略缺失。
- 隐私协议版本未冻结，或授权签署/撤回流程未验收。
- 真实 AI/语音接入缺供应商、HTTPS endpoint、密钥引用、调用日志或人工复核证据。
- 体感游戏缺实机摄像头验收、动作指标入库或审计日志。
- 客户没有确认真实患者数据采集范围、保留周期和导出脱敏规则。
