# 摄像头姿态预检

站位预检使用页面内真实视频作为识别输入，画面仅用于浏览器端识别，不新增图像上传或录像。

检查等待视频播放和有效解码帧，再加载现有模型。首帧等待上限为 8 秒；模型就绪后，在单次最多 5 秒的观察窗口内，每隔至少 200 毫秒检测一个新视频帧。连续 3 个采样帧满足原有质量条件才通过：至少 12 个关键点 visibility ≥ 0.5，全部返回点平均 visibility ≥ 0.45。模型的检测、存在及跟踪阈值保持原值。

这些条件证明连续采样时姿态可见，不证明左右手均入镜、全身完整、动作正确或临床安全。页面不再使用无相应证据的“画面稳定”“双手入镜已确认”描述。

无姿态、关键点质量不足、未连续达标和视频故障分别反馈。检查失败即结束；再次检查由用户主动发起，不自动重开摄像头、不降低门槛。完成、失败或离开页面均停止本次视频流。

自动化测试可验证帧时间、质量判据、取消和资源释放；实际摄像头、光照及人体取景仍需在线交互验收。不能仅凭构建或测试通过认定原问题已经在用户设备解决。
