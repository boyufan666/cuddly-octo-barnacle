# 学习演示项目采集范围

本配置依据项目负责人2026-11-10的说明制定：本项目用于客户学习，不投入真实医疗使用。下述规则用于演示技术流程，不构成临床适应证、禁忌证、医疗处方或安全性结论。

## 适用范围

- 本轮验证只操作专用虚构验收患者；不采集真实患者资料，不把演示结果用于诊断或疗效评价。
- 身体状况标签：`no_known_limitations`、`upper_limb_limited`、`wheelchair`。
- 风险标签：`low`、`moderate`、`high`。允许这些标签是为学习不同分支，不表示相应现实人群可以安全训练。保留原有风险确认、医生方案确认、授权和批次校验。
- 游戏范围：本次已发布的7项浏览器体感、memory_path认知、rhythm_reach_3d Unity；未完成资源不接入。
- 按项目负责人后续明确要求，沿用正式接口与普通技术名称，配置中不添加演示标记；学习项目用途在本说明记录。技术阈值须注明来源，不得标注clinician_approved或伪称医师批准。

## 技术门槛

浏览器体感按各游戏正式运行库定义的指标、输入模式和质量门槛登记，不降低门槛以制造通过。认知按真实运行时的触控/点击输入与结果契约登记。Unity姿态质量阈值由本项目自主选择为演示工程参数，须在发布证据明确数值与来源，不当作临床阈值。所有模式必须沿现有结果校验路径，不补造指标，不添加自动切换、重试或其他fallback。

摄像头游戏需要操作者主动授权、清晰可见且活动空间足够；演示动作仅在操作者舒适范围内进行，不要求极限关节角度、不进行负重或站立平衡挑战。出现不适立即停止。认知可以先用于验证无摄像头依赖的技术闭环。

## 验证与边界

本轮可创建演示协议，确认专用虚构患者方案并准备批次；只有真实交互产生的结果才允许进入完成/复核流程。API准备成功不能代替真实动作、摄像头和音频现场验证。

当前产品没有独立sandbox字段或数据库隔离；“学习演示”名称与元数据不是访问控制，不保证只允许虚构患者使用。演示记录会进入现有业务库和统计。不得将该配置迁移解释为真实医疗准入；若未来改变用途，应单独重新定义规则和验收。
