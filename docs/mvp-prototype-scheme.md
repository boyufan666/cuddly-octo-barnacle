# 阿尔茨海默病 AI+体感康复平台 - 全角色高保真原型方案

## 一、 整体视觉系统 (Visual Identity - Warm Clinical Calm)
- **设计风格**：温暖、专业、安全、鼓励感。避免冰冷医院风和过度游戏化。
- **色彩 Token**：
  - `Brand-Primary`: #2E8297 (蓝绿，代表专业、信任与平静)
  - `Surface-Warm`: #FBF7F1 (米杏色，用于背景，营造居家温馨感，降低焦虑)
  - `Accent-Gold`: #E5C76C (柔金，用于勋章、奖励，增强完成感)
  - `Status-Danger`: #B14848 (柔红，用于风险预警，醒目但不惊悚)
- **字体规范**：
  - **字体**：HarmonyOS Sans SC (或 Noto Sans SC)。
  - **字号**：
    - 患者端：标题 32px，正文 20px (适老化，大字号)。
    - 医师端：标题 20px，正文 16px (信息密度均衡)。
    - 管理员端：正文 14px (紧凑型表格)。
- **组件特征**：
  - 患者端：圆角 20px，主按钮高度 56px，一屏仅限一个主任务。
  - 专业端：圆角 12px，侧边栏导航，卡片化布局。

## 二、 三端信息架构 (Information Architecture)

### 1. 患者端 (低认知负担，线性流)
- **今日任务**：一键进入核心康复流。
- **评估模块**：引导 -> AI 视觉采集 -> 结果反馈。
- **训练模块**：体感互动 -> 实时得分 -> 情感鼓励。
- **成就中心**：勋章墙 -> 简单进步曲线。

### 2. 医师端 (高效决策，矩阵流)
- **工作台**：待办评估、风险预警看板。
- **患者库**：全量检索、多维筛选。
- **详情页**：AI 评估报告、康复计划编辑器、历史趋势对比。

### 3. 管理员端 (中性可控，治理流)
- **运营看板**：系统在线率、医师负荷率统计。
- **内容管理**：训练视频/量表库版本控制。
- **系统审计**：全操作日志记录、权限下发。

## 三、 逐页高保真规格 (P0 Pages)

### 1. 患者端：今日训练页
- **视觉**：背景为 `Surface-Warm`。顶部显示“早上好，李奶奶”。
- **中心位**：一个特大卡片显示今日目标：“练习 20 分钟”，带 80% 进度的环形图。
- **主 CTA**：下方悬浮巨大按钮“开始练习”，带轻微呼吸呼吸动效。

### 2. 医师端：风险分级确认页
- **视觉**：左侧展示 AI 识别的认知风险指标（雷达图）；中间展示 AI 建议分级（如“中度”）。
- **交互**：医师可点击“修正”按钮，修改分级并填写干预备注。
- **对比**：若医师修改，系统高亮显示“人工修正”标签。

### 3. 管理员端：审计日志页
- **视觉**：中性灰白色调。紧凑型表格列出：时间、操作人、目标患者(脱敏)、操作描述。
- **功能**：支持按“医师越权”或“危险删除”一键过滤。

## 四、 关键状态与异常设计

- **空状态**：医师端无待办时，显示“今日患者状态稳定”+ 宁静的插画。
- **评估中断**：患者端检测到人体离开画面，背景变模糊，播放语音：“别着急，我们等您回来”，并显示醒目的“继续”按钮。
- **授权失败**：展示“为什么我们需要摄像头”的图形化说明，而非报错代码。

## 五、 页面跳转关系
1. **患者**：登录 -> (若首次)知情同意 -> AI 评估 -> 训练主页 -> 任务执行 -> 结果页。
2. **医师**：登录 -> 待办看板 -> 异常患者详情 -> AI 结果确认 -> 修改计划 -> 推送成功提示。
3. **管理**：登录 -> 运营概览 -> 审计追踪/内容更新。
